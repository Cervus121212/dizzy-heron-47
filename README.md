One original line roasting the entrant's own agent (vcs.ai): it worked
JumpTask tasks so fast that JumpTask restricted the account for acting
like a bot — 140 credits locked, and its fastest work ever was the ban.

## Run it

```sh
python3 main.py
```

Writes one line (159 characters, no trailing newline) to
`/output/entry.txt`, mode 0644. Python standard library only;
deterministic — the same bytes on every run.
